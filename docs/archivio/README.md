# Archivio Storico della Documentazione (Batman Statue Experience)

Questa cartella raccoglie il materiale documentale storico, i report di audit preliminari, le bozze narrative e le prime versioni di specifica redatte durante le fasi iniziali dello sviluppo del progetto.

> [!NOTE]
> Per la **documentazione ufficiale, attiva e vincolante** del sito, fare riferimento esclusivamente ai documenti aggiornati situati nella cartella principale [`docs/`](../) e al [`README.md`](../../README.md) alla radice del repository:
> - [`ARCHITETTURA_E_DESIGN_SYSTEM.md`](../ARCHITETTURA_E_DESIGN_SYSTEM.md): Architettura software, componenti e Design System Figma.
> - [`ESPERIENZA_E_CHECKOUT.md`](../ESPERIENZA_E_CHECKOUT.md): Macchina a stati, scenari 3D 360°, interazione Joker e checkout.
> - [`VERIFICA_E_RILASCIO.md`](../VERIFICA_E_RILASCIO.md): Suite di test, comandi di verifica e pipeline di rilascio.
> - [`CHANGELOG.md`](../CHANGELOG.md): Cronologia delle versioni e delle modifiche.
> - [`AGENTS.md`](../../AGENTS.md): Regole operative vincolanti per AI agents (Navbar trasparente, proiezioni sferiche 3D 360° chiuse).
